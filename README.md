---

## 📌 Sobre o Projeto

Este projeto consiste num website institucional criado para apresentar serviços, estrutura e informações de um hotel através de uma interface moderna e responsiva.

O objetivo é oferecer uma experiência intuitiva ao utilizador e facilitar o acesso às informações principais.

---

## ✨ Funcionalidades

* Página inicial com apresentação do hotel
* Secção de serviços e comodidades
* Informações sobre quartos ou áreas disponíveis
* Layout responsivo
* Navegação simples e organizada
* Compatível com dispositivos móveis
